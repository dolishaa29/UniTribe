# UniTribe 🚀

A modern and responsive college community platform built using **React**, **Firebase**, and **Tailwind CSS**. UniTribe helps students connect, share ideas, collaborate, and stay updated within their college community through a clean and interactive interface.

---

## 🌟 Features

- 🔐 User Authentication using Firebase
- ⚡ Fast and responsive UI with React
- 🎨 Modern styling using Tailwind CSS
- 📱 Fully responsive design
- ☁️ Firebase integration
- 🔥 Real-time data handling
- 🌙 Clean and user-friendly interface

---

| Technology | Usage |

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/UniTribe.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd UniTribe
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

---

## 🔥 Firebase Configuration

1. Create a project in Firebase
2. Enable Authentication
3. Enable Firestore Database
4. Add your Firebase credentials inside `.env`

```env
VITE_API_KEY=your_api_key
VITE_AUTH_DOMAIN=your_auth_domain
VITE_PROJECT_ID=your_project_id
VITE_STORAGE_BUCKET=your_storage_bucket
VITE_MESSAGING_SENDER_ID=your_sender_id
VITE_APP_ID=your_app_id
```
